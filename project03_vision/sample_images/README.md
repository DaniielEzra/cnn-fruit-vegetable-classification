# Sample images

Five unmodified images from the **Fruits 360** dataset (`Test` folder, 100 x 100 pixels), one per class. Use them to try the website, for example `python test_api.py sample_images\banana.jpg`. The automated tests in `tests/` also use them.

| File | Source folder in Fruits 360 |
|---|---|
| apple.jpg | Test/Apple Red 1/325_100.jpg |
| avocado.jpg | Test/Avocado 1/45_100.jpg |
| banana.jpg | Test/Banana 1/105_100.jpg |
| eggplant.jpg | Test/Eggplant 1/105_100.jpg |
| tomato.jpg | Test/Tomato 1/185_100.jpg |

Source: Mihai Oltean, *Fruits-360 dataset*, 2017-, https://github.com/fruits-360/fruits-360-100x100 (commit 18fbaa1). License: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/. No changes were made.

These images come from the dataset's test set, so in a real training run they may be in the validation or test split. They are for trying the website, not for measuring accuracy.
